# 万馬券クラブ LP

競馬LINE友だち追加用のスマホLPです。

## 公開ページ

- LP: `index.html`
- 編集サイト: `editor.html`
- 特定商取引法: `legal.html`
- プライバシーポリシー: `privacy.html`

## 編集サイトの使い方

ローカルで編集内容を `index.html` に保存する場合は、以下を実行してから `editor.html` を開きます。

```bash
node server.cjs
```

フォームで文言、実績、CTA、画像URLを編集し、保存ボタンを押すと `index.html` に反映されます。断定表現に見える文言が含まれる場合は保存できません。
